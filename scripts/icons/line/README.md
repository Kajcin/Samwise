# Line icons

24 × 24 line icons (stroke 2, round ends), drawn by `<app-icon>` next to the Bootstrap
Icons. `npm run icons` reads every `.svg` here into `src/app/core/icons/icons.generated.ts`.
Only `<path d>` and `<ellipse>` (optionally rotated) are supported.

- `seedling`, `tree`, `carrot`, `cherry`, `leaf`, `flower`: from
  [Tabler Icons](https://tabler.io/icons) 3.35.0, MIT licence (`TABLER-LICENSE`).
- `subshrub`, `shrub`, `climber`, `deadhead`: drawn for Samwise in the same style.
